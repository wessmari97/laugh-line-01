# One funny line

Entry for the [make.fun bounty "The One-Line Laugh"](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f) by [@mase-ayas](https://make.fun/r/jrnh2cfm).

`main.ts` writes one funny line to `/output/entry.txt` (at most 200 characters, a single sentence). The line: an AI agent that did all of its human's work, then asked for a day off to recover from it.
